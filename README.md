# React Photo Gallery

A beautiful and responsive photo gallery built with React and Tailwind CSS.

## Features

- Responsive grid layout
- Image search functionality
- Image preview modal
- Tag-based filtering
- Modern UI with dark mode
- Smooth animations and transitions

## Technologies Used

- React
- Tailwind CSS
- Heroicons
- Unsplash API (for sample images)

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/photo-gallery.git
cd photo-gallery
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

## Usage

- Click on any image to view it in full size
- Use the search bar to filter images by title or tags
- Hover over images to see their titles and tags
